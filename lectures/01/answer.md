## 宿題

- 取り組んだレベル：実装
- やったこと：`app/ask.py` に `--chat` を追加した。SDKの `client.chats.create(model=MODEL)` で会話を1つ作り、同じセッションに `send_message` で質問を送る。SDKがユーザーとモデルの発言を保持するため、前の応答を踏まえて追加質問できる。従来の1回だけの質問方法も使える。
- 結果：初回の質問に回答したあと、次の質問の入力を受け付ける。空白だけの入力ではAPIを呼ばず、`/exit`・`/quit`・入力終了・入力待ち中のCtrl+Cで終了する。各回答で入力・出力トークン数を表示する。会話中にAPIエラー（レート制限の429など）が起きても会話は終了せず、既存の日本語メッセージを表示して次の質問を受け付ける。SDKは成功した応答だけを履歴に追加するため、失敗した質問は履歴に残らず、そのまま聞き直せる。APIを使わないテストを `tests/test_ask.py` に追加した。実モデルによる会話の内容確認は未実施。
- 気づき・疑問：履歴を保持すると「それを具体例で説明して」のような質問ができる。一方、履歴も入力の一部になるので、長い会話ほど入力トークン数が増え、コンテキスト長や利用枠に注意が必要になる。履歴は実行中のメモリーだけに保持し、終了すると破棄される。

### 実APIでの確認方法

検証結果：Python 3.12・`uv.lock` の固定依存を使い、`uv run --python 3.12 --frozen pytest -q` で **18 passed**。追加した7件のテスト（会話中のAPIエラー後に続けて質問できることの確認を含む）も通過した。ローカルの一時導入先の uv を PATH に追加して実行した。

環境変数 `GEMINI_API_KEY` を設定した環境で実行する（キーは解答やコードに書かない）。

```bash
uv run python -m app.ask
uv run python -m app.ask --chat "LoRAとは何ですか？"
```

対話モードでは「それを具体例で説明して」と続け、前の質問を踏まえた回答になることと、各回のトークン数を確認する。`/exit` で終了する。

実装の参考：[Google Gen AI SDK公式ドキュメント](https://googleapis.github.io/python-genai/)。
